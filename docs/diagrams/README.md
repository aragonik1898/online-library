# Диаграммы проекта

Этот каталог содержит PlantUML диаграммы, описывающие архитектуру и структуру проекта "Электронная библиотека".

## Список диаграмм

### 1. architecture.puml
**Архитектурная диаграмма**
- Показывает слои приложения
- Связи между компонентами
- Разделение ответственности

### 2. database.puml
**Схема базы данных**
- ER-диаграмма всех таблиц
- Связи между сущностями
- Описание полей и ограничений

### 3. user-flow.puml
**Пользовательские сценарии**
- Последовательность действий пользователя
- Взаимодействие с интерфейсом
- Основные функции приложения

### 4. deployment.puml
**Диаграмма развертывания**
- Docker контейнеры
- Внешние зависимости
- Процесс разработки и деплоя

### 5. class-diagram.puml
**Диаграмма классов**
- Модели данных
- Контроллеры
- Сервисы
- Связи между классами

### 6. use-case.puml
**Use Case диаграмма**
- Роли пользователей
- Функциональные требования
- Связи между актерами и use case
- Включения и расширения

### 7. sequence.puml
**Диаграмма последовательности**
- Взаимодействие компонентов
- Временная последовательность
- Основные сценарии использования
- Обработка ошибок

## Как использовать

### Просмотр диаграмм

1. **Онлайн редактор PlantUML:**
   - Перейдите на http://www.plantuml.com/plantuml/uml/
   - Скопируйте содержимое .puml файла
   - Вставьте в редактор

2. **Локальная установка PlantUML:**
   ```bash
   # Установка через npm
   npm install -g node-plantuml
   
   # Генерация PNG
   puml generate architecture.puml
   ```

3. **VS Code расширение:**
   - Установите "PlantUML" расширение
   - Откройте .puml файл
   - Нажмите Alt+D для предварительного просмотра

### Редактирование диаграмм

1. Откройте .puml файл в текстовом редакторе
2. Внесите необходимые изменения
3. Проверьте синтаксис в онлайн редакторе
4. Обновите диаграмму в проекте

## Синтаксис PlantUML

### Основные элементы

```plantuml
@startuml
title Заголовок диаграммы


' Участники
actor "Пользователь" as User
participant "Система" as System

' Связи
User -> System : Запрос
System --> User : Ответ

' Группировка
package "Группа" {
    [Компонент1]
    [Компонент2]
}

@enduml
```

### Типы диаграмм

- **Sequence** - последовательные диаграммы
- **Class** - диаграммы классов
- **Component** - компонентные диаграммы
- **Deployment** - диаграммы развертывания
- **Activity** - диаграммы активности

## Обновление диаграмм

При изменении архитектуры приложения обновите соответствующие диаграммы:

1. **Добавление новых моделей** → обновите `class-diagram.puml` и `database.puml`
2. **Изменение контроллеров** → обновите `class-diagram.puml` и `user-flow.puml`
3. **Новая архитектура** → обновите `architecture.puml`
4. **Изменение развертывания** → обновите `deployment.puml`

## Лучшие практики

1. **Используйте понятные имена** для компонентов и связей
2. **Добавляйте заметки** для объяснения сложных частей
3. **Группируйте связанные элементы** в пакеты
4. **Поддерживайте актуальность** диаграмм при изменениях кода
5. **Используйте единый стиль** во всех диаграммах

## Troubleshooting

### Частые ошибки

1. **Синтаксические ошибки**
   - Проверьте правильность скобок
   - Убедитесь в корректности ключевых слов

2. **Проблемы с отображением**
   - Проверьте кодировку файла (UTF-8)
   - Убедитесь в корректности PlantUML синтаксиса

3. **Большие диаграммы**
   - Разбейте на несколько диаграмм
   - Используйте группировку и пакеты
   - Скрывайте несущественные детали
