# Описание рабочих модулей

## Обзор системы

Электронная библиотека состоит из следующих основных модулей:

## 1. Модуль аутентификации и авторизации

### Компоненты:
- **AccountController** - управление пользователями
- **ApplicationUser** - модель пользователя
- **ASP.NET Core Identity** - система аутентификации

### Функции:
- Регистрация новых пользователей
- Вход в систему
- Управление профилем
- Выход из системы
- Валидация данных пользователя

### Зависимости:
- Entity Framework Core
- ASP.NET Core Identity
- SQLite база данных

---

## 2. Модуль управления книгами

### Компоненты:
- **BooksController** - контроллер книг
- **Book** - модель книги
- **FileService** - сервис работы с файлами

### Функции:
- Просмотр каталога книг
- Поиск и фильтрация книг
- Просмотр деталей книги
- Загрузка PDF файлов
- Управление метаданными книг

### Зависимости:
- ApplicationDbContext
- FileService
- PaginationService

## Взаимодействие модулей

### Основные потоки данных:

1. **Пользователь → Контроллер → Сервис → БД**
2. **Контроллер → View → Пользователь**
3. **Сервис → File System → Пользователь**

### Ключевые зависимости:

- Все контроллеры зависят от ApplicationDbContext
- FileService используется в ReadingController
- PaginationService используется во всех списках
- Identity интегрирован во все защищенные функции

### Принципы архитектуры:

- **Separation of Concerns** - разделение ответственности
- **Dependency Injection** - внедрение зависимостей
- **Repository Pattern** - через Entity Framework
- **Service Layer** - бизнес-логика в сервисах
